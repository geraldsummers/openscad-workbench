# Security policy

## Supported version

Security fixes are applied to the latest commit on the default branch. This
project does not currently maintain older release branches.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not include credentials, private models, or other sensitive data in a public
issue.

Include the affected command, environment, reproduction steps, impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.
