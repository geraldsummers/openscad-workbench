# Drone Playground Suite

Twelve assembled obstacles built from 18 unique printable parts. All dimensions are millimetres.

| Obstacle | Printable parts | Assembly note |
|---|---|---|
| Serpentine canyon | canyon left + canyon right | Space bases about 270 mm apart for a 200 mm flight channel. |
| Corkscrew tunnel | tunnel | 200 mm clear bore with an exterior spiral marker. |
| Dive chimney | chimney | 220 mm clear skeletal shaft for top-entry/side-exit lines. |
| Split-decision wedge | wedge | Place as a route-splitting island. |
| Orbit tower | tower | Three staggered radial flags define orbit height and direction changes. |
| Over-under bridge | bridge | 200 × 120 mm clear underpass and 220 × 90 mm landing roof. |
| Bullseye pedestal | pedestal | 140 mm landing disc at 100 mm height. |
| Landing staircase | staircase | 80 mm pads at 50, 90, and 130 mm. |
| Seesaw | base + deck | Drop the 6 mm deck axle into the open 6.6 mm saddles. |
| Carousel | base + rotor + cap | Place rotor over the 6 mm spindle, then fit the cap. |
| Pendulum gate | gantry + paddle | Drop the 6 mm paddle axle into the open 6.6 mm cradle. |
| Saloon gate | frame + door printed twice | Seat one door at each side, mirrored as shown. |

Static bases use plain 4.5 mm through-holes. The moving interfaces use 6.0 mm axles and 6.6 mm running bores. Printed fit, motion, balance, impact safety, and fastener selection require a physical prototype before flight use.

Each part directory contains `model.scad`, verified STL and 3MF exports, ten inspection views, a contact sheet, and a verification report. The `renders` directory contains the upper-isometric assembled views shown in Herdr.
