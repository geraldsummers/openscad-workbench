# Reference block specification

## Requirements

- [overall-size] Overall dimensions are 40 x 30 x 12 mm: mesh-verified by `model.toml`.
- [corner-radius] Vertical edges have a 2 mm radius: source-verified by the radius assertion and its pass marker.
- [intended-shape] The block is one upright rounded rectangular solid without unintended features: visually verified in all ten views, including both underside isometrics.

## Exclusions

This reference fixture does not assess slicing, materials, nozzles, supports, overhangs, or toolpaths.
